# Produto

O Entrelinhas apoia estudantes que querem tirar dúvidas. A pessoa escreve uma pergunta e recebe uma explicação em português. Cada pergunta é independente: não há histórico, autenticação ou banco de dados. Respostas de IA podem estar incorretas e devem ser conferidas em fontes confiáveis. Não envie dados pessoais ou confidenciais.
